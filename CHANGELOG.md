# Changelog

## 0.1.0 — 2026-10-10

- Adds the installed app's native Message Rail to ordinary Chat pages.
- Shows the rail after four user messages.
- Supports native hover previews, local bookmarks, smooth reveal, current-item highlighting, and collapse/expand.
- Hydrates Chat history in the background while preserving the latest-message viewport.
- Keeps loaded previews in an in-memory session cache.
- Adds loopback-only CDP launcher and cleanup scripts for Windows.
